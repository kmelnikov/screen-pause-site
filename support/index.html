First launch

Mac App Store edition: open Screen Pause and run the fixed 10-second test pause in Settings → Access. No Accessibility or Input Monitoring permissions are required.

Direct DMG edition:

  1. Move Screen Pause to Applications first, then open it.
  2. In Screen Pause, open Settings → Access and choose Allow beside Accessibility and Input Monitoring.
  3. Enable Screen Pause in both macOS Privacy & Security lists.
  4. Return to Screen Pause. Both permission rows should say Granted.
  5. Run the fixed 10-second test pause before a longer break.

The test covers every display, then returns control automatically. It does not change your series’ progress or add a pause to your statistics. For a simple first schedule, choose Fixed with one series and leave Auto off so the app asks first.

Ending a pause

A pause ends automatically when its bounded timer reaches zero. To end it early, press Control–Option–Command–Escape. An emergency release is not recorded as completed rest and suspends Auto Pause until it is resumed manually.

Reinstalling and restoring permissions

Keep the edition you installed: use the Mac App Store for its edition and TestFlight for a test build. Avoid keeping several copies of Screen Pause in Applications. Copies from different channels can require separate permission approval even when their names match.

For the direct edition, keep the app in Applications and replace the previous copy in the same location. If a permission no longer says Granted, remove the stale Screen Pause entry from that Privacy & Security list, add the current application again, and run the 10-second test.

Direct download and Mac App Store

The direct edition is available through Gumroad; the Mac App Store edition is coming soon. The direct-download build uses Accessibility and Input Monitoring for system-wide input suppression and can manage active system media and safely restorable keyboard backlight state. The Mac App Store build runs inside App Sandbox without Accessibility or Input Monitoring permissions, uses standard macOS full-screen pause windows, leaves media playback and keyboard backlight under macOS control, and does not infer rest from ordinary input inactivity.

Privacy

Screen Pause has no account, analytics, advertising, telemetry, or network communication. Settings and timing records stay on the Mac. Input contents and application names are never stored. Read the full privacy statement.
