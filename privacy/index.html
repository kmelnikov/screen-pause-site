Privacy

Everything stays on your Mac.

Screen Pause does not transmit or sell personal data. It has no account system, analytics, advertising, telemetry, crash reporting, or network communication.

Input permissions

In the direct-download build, macOS Accessibility and Input Monitoring permissions are required solely to discard keyboard, mouse, trackpad, scroll, and media-key events during an active pause. Event contents are not recorded, inspected for text, written to disk, or transmitted.

The Mac App Store build runs inside App Sandbox and does not request Accessibility or Input Monitoring permissions. During an active pause, it presents standard macOS full-screen pause windows and handles only local in-pause commands inside its own active window. Input is never recorded, logged, written to disk, or transmitted.

Local data

The app stores the selected duration, Auto Pause settings including any optional pause intention written by the user, suspension state, keyboard shortcuts, and the start time, source, planned duration, and actual time away for up to 200 recent pauses.

While Adaptive feedback is pending, the relevant series retains only numeric work time, observed rest duration, and whether the blackout was intentionally extended. That temporary context is cleared when the feedback is resolved or discarded and contains no application or input-event content.

Screen Pause also stores the current day’s active-use time, completed pause time, ordered active-use segments containing start time, end time, and duration, and aggregate Auto Pause responses. Completed daily records are retained for the latest 30 local days; older days are deleted automatically. These records contain no input contents or application names.

Media

The direct-download build reads only whether macOS reports system media as playing, so passive playback is not classified as rest and playback can be paused during a break. It does not read or store titles, artists, URLs, artwork, or playback history. The Mac App Store build does not access media state.

Absence detection

A qualifying absence is derived only from elapsed time since the last keyboard, mouse, or trackpad event. In the direct build, active media playback prevents an absence from being classified as rest. In the Mac App Store build, ordinary input inactivity is not inferred as rest; explicit system sleep can count.

Scope

This statement applies to Screen Pause 1.6.68. All records remain on the Mac and are never transmitted. The fixed 10-second test pause is not added to Today or Pause History.
